# Pati Defteri

Kişisel görevleri yönetmek ve görev tamamladıkça sanal bir kediyi büyütmek için yapılmış, telefonda ve bilgisayarda çalışan bir web uygulaması (PWA).

Site: https://grpnrfrkn.github.io/pati-defteri/

Durum: Aşama 1 (görev yönetiminin temeli) hazır. Sırada Aşama 2 var: takvim, arama ve filtreler, Günü Toparla.

## Geliştirme

```bash
npm install
npm run dev
npm test
```
